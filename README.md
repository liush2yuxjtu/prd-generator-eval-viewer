# PRD Generator — Eval Viewer

Static, read-only review of five PRD Generator hill-climb examples. Generated using Anthropic's official [Skill Creator eval viewer](https://github.com/anthropics/skills/tree/main/skills/skill-creator/eval-viewer) and source data from a separate private evaluation project.

Includes all five user inputs, complete model-generated PRDs, grader feedback and scores, previous baseline outputs, and benchmark comparison.

**Scores:** baseline 97.6/100; final 100/100 (five training examples); two unseen controls 100 and 96 (mean 98). This is a single-model Grader score and does not prove universal PRD quality.

No API keys, tokens, or server endpoints are included. HTML is standalone and does not invoke any model API.
